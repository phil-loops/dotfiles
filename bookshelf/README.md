# Bookshelf

Reading lists, one file per idea. Each shelf says what the idea is, where it bit, what to read, and has a `Notes` section at the bottom for my own words.

A shelf is done when I can explain the idea without the links.

Read it in the browser with `scripts/bookshelf-serve` (the 📚 row in the ✦ menu, :62556): ticking a box or typing notes there writes straight back to these files. Progress is the checkboxes, so there is no status column to keep in step.
