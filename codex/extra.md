# Rules for every agent Phil runs

These rules are shared by Claude Code and Codex; they were first written for Claude, so where they say "Claude", read "you". Mechanics only Claude has (its skills, Show's Inbox, its memory) are left out. To change a rule, edit `~/.dotfiles/CLAUDE.md` or `~/.dotfiles/claude/*.md` and run `agent-rules` — never this file. A lesson Phil gives you that isn't here yet goes into those sources the same way: fold it into the principle it instances.
